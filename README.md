Site institucional desenvolvido para a **MG Padroniza**, com o objetivo de apresentar os serviços da empresa, sua identidade e seus canais de contato.

## 📌 Sobre o projeto

O projeto foi desenvolvido como uma página institucional, buscando criar uma navegação simples, organizada e visualmente agradável.

O site conta com seções para:

- 🏠 Início
- 🛠️ Serviços
- 👥 Quem Somos
- 📋 Contato e Cotações
- 💻 MG Tech

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎨 Características

- Design responsivo
- Navegação entre seções
- Menu fixo
- Destaque da seção atual no menu
- Layout adaptado para diferentes tamanhos de tela
- Identidade visual baseada nas cores da MG Padroniza
